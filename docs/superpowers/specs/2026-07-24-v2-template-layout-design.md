# 单词卡片转换 v2 — 模板排版读取 设计规格

**日期**: 2026-07-24  
**状态**: 已批准  
**来源**: v1 重构完成后，新增用户自定义排版功能

---

## 1. 概述

当前 v1 使用内嵌的固定 PPTX 模板。v2 改为：用户在 PowerPoint 中自行设计排版 → 软件读取模板 → 填入 Excel 数据。

### 1.1 目标

- 用户手动设计 PPTX 模板（文本位置、字体、大小、颜色自由控制）
- 软件读取模板中的 `{{占位符}}` 标记，记录位置和格式
- 批量替换 `{{...}}` 为 Excel 数据，生成 PPTX
- 提供 `template-pptx` 命令，生成含标准占位符的示例模板

### 1.2 非目标

- 不做 GUI 模板编辑器
- 不支持从模板中提取格式再应用到其他模板（格式跟着模板走，不分离）
- 不自动识别字段（必须用 `{{...}}` 标记）

---

## 2. 占位符规范

| 占位符 | 对应 Excel 列 | 必填 |
|--------|-------------|------|
| `{{单词}}` | 英文单词 | 是 |
| `{{音标}}` | 英文音标 | 否 |
| `{{词根词缀}}` | 词根词缀 | 否 |
| `{{例句}}` | 例句 | 否 |
| `{{例句释义}}` | 例句释义 | 否 |
| `{{单词释义}}` | 单词释义 | 否 |

- 用户模板中可选择性使用——不需要的字段不放占位符即可
- 多余占位符（不在上述列表中的 `{{...}}`）会原样保留，不做替换
- 占位符可以在同一文本框内多次出现

---

## 3. 模板读取流程

```
1. 用户打开 我的模板.pptx
2. 软件读取 ppt/slides/slide1.xml
3. 扫描所有 <a:t> 标签，匹配 {{...}} 模式
4. 对每个匹配的占位符:
   - 记录所在 shape 的位置/格式（从 <a:xfrm> 和 <a:rPr>/<a:defRPr> 提取）
   - 记录占位符在 <a:t> 内的位置（用于保留前后文字）
5. 后续替换: 克隆 slide1.xml → replace("{{单词}}", actual_word) → ...
```

### 3.1 保留文字示例

```
模板: "词根词缀：{{词根词缀}}"
数据: morphology = "ap-ple"
结果: "词根词缀：ap-ple"
```

## 4. 架构变化

### 4.1 generator 模块

```rust
/// 读取模板 PPTX，替换占位符为数据，输出 PPTX
pub fn generate_from_template(
    entries: &[WordEntry],
    template_path: &Path,   // 用户提供的模板
    output: &Path,
    progress: impl Fn(usize, usize) -> bool,
) -> Result<(), GenerateError>;
```

### 4.2 文件变化

- **新增**: `crates/core/src/template_reader.rs` — 扫描 slide XML，提取占位符位置
- **修改**: `crates/core/src/generator.rs` — 新增 `generate_from_template()`
- **删除**: `crates/core/assets/template.pptx` — 不再内嵌固定模板
- **修改**: `crates/cli/src/main.rs` — 新增 `--template` 参数、`template-pptx` 子命令

### 4.3 CLI

```bash
# 使用自定义模板
单词卡片转换 generate -i data.xlsx -t 我的版式.pptx -o output.pptx

# 批量
单词卡片转换 batch -i ./data/ -t 我的版式.pptx -o ./output/

# 生成示例模板（含六个标准占位符）
单词卡片转换 template-pptx -o 示例模板.pptx
```

## 5. 示例模板生成

`template-pptx` 命令生成一个包含六个字段占位符的示例 PPTX：

```
┌──────────────────────────────────────────────┐
│             {{单词}}            ← 72pt 加粗居中 │
│              {{音标}}            ← 28pt 居中    │
│  单词释义：{{单词释义}}          ← 24pt 左对齐  │
│  词根词缀：{{词根词缀}}          ← 24pt 左对齐  │
│  例句：{{例句}}                  ← 24pt 左对齐  │
│  例句释义：{{例句释义}}          ← 24pt 左对齐  │
└──────────────────────────────────────────────┘
```

用户打开这个模板，拖动文本框、改字体、调大小——然后保存为自己的模板。

---

## 6. 技术风险

- **PPTX 多种排版方式**: PowerPoint 文本框格式可能存储在 `<a:rPr>` 或 `<a:defRPr>` 中，需兼容
- **多段落**: 一个 shape 可能有多个 `<a:p>` 段落，占位符可能跨段落
- **模板中无 `{{单词}}`**: 没有单词占位符 → 报错，因为这是必填字段
- **模板删除后重新引用**: 用户可能修改模板后需要重新选择，需做文件存在检查
